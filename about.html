📖 About This Project

Computer Parts Map is a free, open-source educational website that serves as an interactive encyclopedia for computer hardware. It was built to fill a gap — most hardware guides are either too technical for beginners or too shallow to be genuinely useful.

This project covers 20+ hardware components across 6 categories, with each page containing detailed explanations, real product recommendations, spec comparison tables, and historical context. Everything is built from scratch using pure HTML, CSS, and Vanilla JavaScript — no frameworks, no build tools.

📺 Satch Ka Switch — YouTube Network

Satch Ka Switch is an independent YouTube network focused on data-driven, analytical content about the Indian education system and career conformity. The channel takes a skeptical, root-cause approach to socio-economic issues — asking uncomfortable questions that mainstream media ignores.

The network includes a Bengali language channel for deeper, more nuanced discussions.
