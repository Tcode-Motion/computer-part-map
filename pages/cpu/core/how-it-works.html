How a CPU Works — Step by Step

A CPU is a machine that reads instructions from memory, decodes them, executes them, and writes results back — billions of times per second.

”„ The Fetch-Decode-Execute Cycle

Every CPU, from the Intel 4004 to the Ryzen 9950X, follows the same fundamental cycle:

StepNameWhat HappensComponent
1FetchCPU reads the next instruction from memory using the Program Counter (PC/RIP)Instruction Fetch Unit, L1 I-Cache
2DecodeInstruction is broken down into operations the CPU can perform (micro-ops in x86)Instruction Decoder
3ExecuteThe ALU, FPU, or other execution unit performs the operationALU, FPU, AGU, BRU
4Memory (if needed)Load data from memory or store results to memoryLoad/Store Unit, L1 D-Cache
5Write BackResult written to destination registerRegister File
