Branch Prediction — How CPUs Predict the Future

Modern CPUs predict which branch of code will execute next with 97%+ accuracy, keeping the pipeline full and avoiding costly stalls.

“– What is Branch Prediction?

In any program, there are branch instructions — conditional jumps like if/else, loops, and function calls. When the CPU encounters a branch, it doesn't yet know which path to take because the condition hasn't been evaluated.

Rather than stalling the entire pipeline 20+ cycles, the CPU predicts the likely outcome and speculatively executes instructions along that predicted path. If the prediction is correct (97%+ of the time), no time is wasted. If wrong (a misprediction), the pipeline must be flushed and restarted — losing 15-30 cycles.

’¡ Did You Know?

Modern branch predictors like TAGE (used in AMD Zen and Intel cores) achieve 97-99% accuracy. A program may have billions of branches, so even 1% misprediction rate means millions of pipeline flushes.

’”Spectre — When Branch Prediction Becomes a Vulnerability

In January 2018, researchers disclosed Spectre — a class of security vulnerabilities that exploit speculative execution (which relies on branch prediction). During mispredicted speculative execution, the CPU temporarily accesses data it shouldn't, leaving traces in the cache that an attacker can read.
