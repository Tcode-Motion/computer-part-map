CPU Threads — Hyper-Threading & SMT

A thread is a sequence of instructions that can be executed independently. Modern CPUs use SMT to run 2 threads per core simultaneously.

“– What is a Thread?

In computing, a thread is the smallest sequence of programmed instructions that can be managed independently by a scheduler. Think of a core as a worker, and threads as tasks that worker can handle.

With Simultaneous Multi-Threading (SMT) — Intel calls it Hyper-Threading (HT) — a single physical core can handle two threads at once. It achieves this by duplicating certain parts of the core (register files, instruction queues) while sharing the execution units.

’¡ Did You Know?

IBM's POWER10 processor supports 8-way SMT — each core can run 8 threads simultaneously! A 15-core POWER10 can handle 120 threads. Most consumer CPUs support 2-way SMT.

Apple's approach: Apple Silicon chips have no SMT. Instead, they use a large number of physical cores with extremely wide execution units. This avoids the complexity of thread scheduling and reduces power consumption.
