CPU Pipeline — Instruction Pipelining

Pipelining is the technique that lets CPUs process multiple instructions simultaneously by overlapping stages — like an assembly line in a factory.

“– What is Pipelining?

Without pipelining, a CPU would finish one instruction completely before starting the next. Pipelining breaks each instruction into stages and processes them in an overlapping fashion — while Instruction 1 is at the Execute stage, Instruction 2 is Decoding, and Instruction 3 is being Fetched.

This is analogous to a factory assembly line: no worker waits idle, each handles a different stage of production at the same time.

“Š Classic 5-Stage Pipeline

StageAbbreviationWhat Happens
1. Instruction FetchIFRead the next instruction from L1 instruction cache using the Program Counter
2. Instruction DecodeIDDetermine what the instruction does and read source registers
3. ExecuteEXALU performs the computation (add, compare, shift, etc.)
4. Memory AccessMEMIf needed, read from or write to memory (load/store)
5. Write BackWBWrite the result to the destination register

The Pentium 4's 31-stage pipeline allowed 3.8 GHz clocks, but a branch misprediction wasted 31 cycles of work. The Core architecture returned to ~14 stages, sacrificing some clock speed for much better efficiency.
