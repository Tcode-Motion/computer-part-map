CPU Bus & Interconnects

The bus is the data highway connecting the CPU to memory, storage, GPU, and other components. Modern interconnects move data at hundreds of GB/s.

“– What is a Bus?

A bus is a communication system that transfers data between components in a computer. Historically, a "Front-Side Bus" (FSB) connected the CPU to the North Bridge chipset. Modern CPUs use direct connections and high-speed serial interconnects instead.
