RAM Types

Advanced documentation and architecture breakdown for Random Access Memory.

📖 Overview

RAM provides high-speed, volatile data storage for the CPU. It is essential for multitasking and quick data retrieval during program execution.

⚙️ Architecture & Working Principle

RAM consists of memory cells built from a capacitor and a transistor. Cells are organized into arrays (banks), accessed via rows and columns by memory controllers.

The CPU sends a memory address to the memory controller, which activates the corresponding row and column. The data is read by sense amplifiers and sent to the CPU.
