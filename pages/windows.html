📜 History

Launched in 1985 as a GUI for MS-DOS. Windows NT (1993) introduced the modern 32-bit/64-bit architecture. Key versions include Windows 95, XP, 7 (beloved for stability), 10 (universal OS), and 11 (modern overhaul). Note: Windows 9 was skipped to avoid confusion with Windows 95/98 legacy code checks.

🏗️ Architecture

Hybrid Kernel (Windows NT). Uses subsystems (Win32, POSIX, OS/2 historically) and a Hardware Abstraction Layer (HAL). It employs the NTFS file system and the Windows Registry for system-wide configuration.
